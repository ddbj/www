2026年10月21日のシステムリリースにより、[BioProject](/bioproject/index.html) の登録項目を以下のとおり変更しました。

- **Project data type の拡張**: 
以下の type を追加しました。
* Genome Sequencing and Assembly
* Raw Sequence Reads
* Assembly
* Metagenomic Assembly
* Targeted Loci Cultured
* Targeted Loci Environmental 
* Metabolome
- **入力項目の廃止**: Objective、Material、Capture、Methodology の入力項目を廃止しました。
- **文字数制限の追加**: Project title を 20〜250 文字、Public description を 20〜4,000 文字（いずれも空白を含む）に制限しました。
- **Umbrella project の非公開対応**: これまで即日公開のみであった umbrella project を非公開（hold）にできるようにしました。
- **非 ASCII 文字の制限**: ウェブのテキスト入力項目（submitter name など）で非 ASCII 文字を入力不可としました。

詳細は [プロジェクト情報](/bioproject/project-info.html) および [プロジェクトの登録](/bioproject/submission.html) をご参照ください。
