With the system release on October 21, 2026, the following changes have been made to the [BioProject](/bioproject/index-e.html) submission fields.

- **Expanded Project data type**: 
The following types have been added.
* Genome Sequencing and Assembly
* Raw Sequence Reads
* Assembly
* Metagenomic Assembly
* Targeted Loci Cultured
* Targeted Loci Environmental 
* Metabolome
- **Removed fields**: The Objective, Material, Capture, and Methodology fields have been removed.
- **Character limits**: Project title is now limited to 20-250 characters, and Public description to 20-4,000 characters (both including spaces).
- **Umbrella project hold**: Umbrella projects, which were previously released immediately, can now be kept private (held).
- **Non-ASCII restriction**: Non-ASCII characters can no longer be entered in web text input fields (e.g., submitter name).

For details, please see [Project information](/bioproject/project-info-e.html) and [Project submission](/bioproject/submission-e.html).
