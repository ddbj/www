To make more efficient use of storage resources and ensure the continued public availability and distribution of a growing volume of sequence data, the DDBJ Sequence Read Archive (DRA) will change the storage and distribution format of mirrored data originating from NCBI and EBI (SRR and ERR accession numbers) from the SRA Normalized (Full) format to the SRA Lite format.

## About the SRA Lite Format

Compared with the SRA Normalized (Full) format, the SRA Lite format simplifies Quality Values (QVs) while preserving base calls, read names, and alignment information.

Specifically, fixed QV values are assigned according to the read filtering status (`Read_Filter`), as follows:

- Read_Filter = pass: Q30
- Read_Filter = reject: Q3

This simplification reduces file sizes by approximately 30–40% on average.

For more details, please refer to the NCBI website: [SRA Data Formats](https://www.ncbi.nlm.nih.gov/sra/docs/sra/)

### How to Identify the File Format

The SRA Normalized (Full) and SRA Lite formats can be distinguished by their file extensions:

- SRA Normalized (Full) format: `.sra`
- SRA Lite format: `.sralite`

Examples:

Before the change (SRA Normalized (Full) format):

`https://ddbj.nig.ac.jp/public/ddbj_database/dra/sralite/ByExp/litesra/SRX/SRX000/SRX000007/SRR000001/SRR000001.sra`

After the change (SRA Lite format):

`https://ddbj.nig.ac.jp/public/ddbj_database/dra/sralite/ByExp/litesra/SRX/SRX000/SRX000007/SRR000001/SRR000001.sralite`

## Impact on Users

- Standard sequence analysis: There is no impact on analyses that use base calls, read names, or alignment information, as these data remain unchanged.
- Analyses that use QVs: Since per-base QVs are replaced with fixed values based on read-level filtering status, analyses that require per-base QVs may be affected. Examples include QV-based trimming, error modeling, and certain variant-calling methods.

Please note that read data submitted to DRA (DRR accession numbers) are not affected by this change. SRA Normalized (Full) format, generated FASTQ files, and the original file formats submitted by users (such as FASTQ and BAM) will continue to be provided as before.

## Scope and Schedule

- Target data: Mirrored data originating from NCBI and EBI (SRR and ERR accession numbers)
- Excluded data: Data submitted to DRA (DRR accession numbers)
- Schedule: The change will be implemented starting November 16, 2026.
